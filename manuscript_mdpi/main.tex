% Abstract (<= ~200 words, one paragraph: background, methods, results, conclusion)
\abstract{Limitation and future-work statements are author-stated research gaps that could seed automated idea generation, but extracting them at scale requires source attribution and controlled processing cost. We study a three-stage funnel: structural localization, a sentence classifier, and a large-language-model (LLM) precision filter applied only to the remaining candidates, which returns source sentences rather than generated descriptions. We evaluate it on full-article limitation detection, future-work recognition, and research-gap sentence classification. On 40 randomized-trial articles (7968 sentences, 205 labelled limitations), localization discards 76.3\% of sentences while retaining 203 positives. A fine-tuned PubMedBERT classifier reaches precision 0.460, recall 0.878, and $F_1$ 0.604; the LLM filter raises precision to 0.580 and $F_1$ to 0.658, with recall falling to 0.761. Filtering only candidates requires an estimated 75,622 input tokens versus 282,846 for full-article prompting, a 3.74-fold reduction that excludes detector computation and output tokens. Baselines, ablations, and prevalence analyses show that method rankings depend on the input condition and target definition. Because prompts were refined on benchmark feedback, LLM results are exploratory, and human validation is documented but not yet completed. The funnel provides a measured precision--recall and cost trade-off for attributable gap extraction, a building block towards automated research idea generation.}
