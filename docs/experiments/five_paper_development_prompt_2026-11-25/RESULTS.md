# Further five-paper development prompt tuning

One request per group of five papers, using the same fine-tuned NLI candidates, original neighboring sentences, Qwen3.8-27B FP8, and positive labels as in the preceding single-prompt study. The 15-paper tuning and 10-paper check groups were fixed in advance. All papers were previously examined during development and the labels are generated by an LLM, with apparent disagreements; the check is exploratory, not an untouched test or human evaluation. Neutral results were reused from the preceding experiment.

The tuning criterion was maximum pooled precision with at least 70% recall. `grounded` and `unresolved` replace the neutral prompt's uncertainty instruction with new wording. `verdicts` leaves the neutral rubric unchanged but restores per-candidate output: `{"results":[{"id":integer,"keep":boolean},...]}` for every candidate. The strict JSON schema was enforced, and the runner required exactly one valid verdict for every input candidate.

| Tuning, 15 papers | TP | FP | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Neutral, positive IDs | 274 | 102 | 72.87% | 78.06% | 75.38% |
| Grounded, positive IDs | 283 | 107 | 72.56% | 80.63% | 76.38% |
| Unresolved, positive IDs | 279 | 93 | 75.00% | 79.49% | 77.18% |
| Neutral, per-candidate verdicts (selected) | 287 | 81 | 77.99% | 81.77% | 79.83% |

| Check, 10 papers | TP | FP | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Neutral, positive IDs | 143 | 113 | 55.86% | 78.14% | 65.15% |
| Neutral, per-candidate verdicts | 137 | 69 | 66.50% | 74.86% | 70.44% |

On check group 4 the positive-ID format achieved P58.57/R67.21 and verdicts P61.29/R62.30; on group 5 they achieved P54.84/R83.61 and P68.75/R81.15, respectively. Thus the observed precision improvement comes with a modest recall loss in both check groups. This is a promising exploratory finding, not evidence of generalization to unseen papers. The two conditions were run at different times on a shared service; one run per condition does not characterize stochastic variation.

For the two check calls, input tokens totaled 61,110 versus 61,118 and output tokens totaled 1,730 versus 5,897 for positive IDs versus verdicts. Per-candidate formatting therefore added 4,167 output tokens, while leaving the input context nearly unchanged. Raw responses, output validation, token use, precise prompts, and frozen plan are saved here. No model service was started or stopped for this study.
