# Fusion of zero-shot and fine-tuned NLI: development check

This is a Stage B analysis using existing zero-shot and fine-tuned ModernBERT NLI scores, not new model inference or an end-to-end Qwen experiment. We split the 34 original development papers into 17 tuning papers (half A) and 17 check papers (half B), stratified by arXiv/biomedical domain. The LLM-derived labels contain 312 and 387 positive sentences respectively. Stage A junk filtering is applied; recall denominators include the positives removed by Stage A.

For each sentence, each model's score is the maximum of three type-specific entailment/(entailment+contradiction) scores. We transform both models' scores to empirical percentiles using the Stage-A-passing sentences in half A, then take a weighted average. We choose each single-model or fusion threshold on half A to achieve at least 90% recall and freeze it before scoring half B. Union and intersection combine the two separately thresholded model decisions. Fusion weights and methods were fixed before scoring.

| Stage B method | Half A passed | Half A precision / recall | Half B passed | Half B precision / recall | Half B F1 |
|---|---:|---|---:|---|---:|
| Zero-shot NLI | 1,081 | 25.99% / 90.06% | 1,250 | 26.48% / 85.53% | 40.44% |
| Fine-tuned NLI | 771 | 36.45% / 90.06% | 940 | 36.60% / 88.89% | 51.85% |
| Fusion: 25% fine-tuned + 75% zero-shot | 842 | 33.37% / 90.06% | 985 | 33.60% / 85.53% | 48.25% |
| Fusion: 50% each | 809 | 34.73% / 90.06% | 935 | 36.04% / 87.08% | 50.98% |
| Fusion: 75% fine-tuned + 25% zero-shot | 707 | 39.75% / 90.06% | 845 | 39.76% / 86.82% | 54.55% |
| Union of independently thresholded models | 1,219 | 23.95% / 93.59% | 1,426 | 24.89% / 91.73% | 39.16% |
| Intersection of independently thresholded models | 633 | 42.65% / 86.54% | 764 | 41.88% / 82.69% | 55.60% |

On half B, the 75%-fine fusion passes 95 fewer sentences than fine-tuned alone, with 8 fewer labeled positives and 87 fewer labeled negatives: measured precision rises by 3.16 points while recall falls by 2.07 points. This is a tradeoff, not a same-recall improvement. At its selected thresholds the intersection is more selective and misses 24 additional labeled gaps compared with fine-tuned alone. The union preserves more labeled gaps but passes more text.

Half B is separate from this threshold fit, but it is **not an independent holdout**: the fine-tuned checkpoint and earlier choices were selected using the whole validation pool, and these papers were previously studied. The labels were generated by LLMs and are not fully human validated. No full-paper baseline, Stage C Qwen calls, monetary or end-to-end runtime benchmarks were run. A fusion pass needs both NLI scores and can add Stage B computation. It could alter Qwen's decisions by changing the input set, so a higher Stage B precision does not establish higher end-to-end precision.

`plan.json`, `results.json`, source-score hashes, paper IDs and the runner `scripts/bench/nli_fusion_development.py` provide the exact thresholds and methodology. The previously explored rank averaging of NLI with a bge-small head reported no gain; this experiment combines the zero-shot and fine-tuned versions of NLI instead. A learned mixture-of-experts router was not trained.
