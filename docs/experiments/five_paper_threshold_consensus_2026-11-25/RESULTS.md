# Precision exploration on the prior 25-paper FP8 comparison

After examining development results, a consensus rule was proposed: run the same 27B FP8 neutral prompt with fine-tuned NLI thresholds 0.002103 and 0.05, with identical neighbor formatting, and keep only sentence IDs accepted by both. This was a **post-hoc development idea**, frozen before the new calls, and the same 25 test papers had already been analyzed in earlier experiments. Therefore the figures below are exploratory, not an independent or human-validated result. The previously saved original-threshold outputs are reused; one new high-threshold call was made for each of the same five paper groups.

| Approach | Qwen calls per five papers | TP | FP | Precision | Recall | F1 | Qwen input tokens |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Original NLI threshold 0.002103 | 1 | 367 | 263 | 58.3% | 76.9% | 0.663 | 210,996 |
| High NLI threshold 0.05 | 1 | 367 | 222 | 62.3% | 76.9% | 0.689 | 91,437 |
| Intersection of both outputs | 2 | 329 | 120 | **73.3%** | 69.0% | **0.711** | 302,433 |

The high-threshold run returned the same number of labeled true positives in aggregate as the original but did not return the identical sentences: 38 labeled gaps were unique to each run. Consensus removed 143 labeled false positives while also removing 38 labeled true positives relative to the original. It used 43.3% more Qwen input tokens than the original single call because it requires both requests. Token totals exclude NLI and preprocessing, and the labels are generated by LLMs, so some apparent false positives may be genuine gaps.

The high-threshold NLI alone passed 709 candidates, containing 379 of 477 labeled gaps (79.5% Stage B recall); the original passed 1,553 candidates containing 434 (91.0%). The apparent equal final true-positive totals arise because Qwen decisions changed when the request changed, not because the high threshold retained the same gaps. The one-call high threshold improved precision on this previously studied 25-paper set but reduced precision on the separate five-paper development check (80.0% to 69.5%), so robustness remains unresolved.

All five new high-threshold requests succeeded with valid IDs. Future confirmation needs an untouched set and blind human review of both selected and rejected sentences, as well as disclosure of the two-request cost and group effects.
