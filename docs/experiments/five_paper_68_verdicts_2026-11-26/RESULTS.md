# Matched Stage C benchmark: 68 development and test papers

We evaluated full-paper Qwen, zero-shot NLI + Qwen and fine-tuned NLI + Qwen on the same 68 original gold validation/test papers (28 arXiv and 6 biomedical in each split). We used the existing model and frozen NLI thresholds, not a newly trained model. Each method used one Qwen3.8-27B FP8 request per group and the same neutral decision prompt with one boolean verdict per input sentence. Groups were constructed separately by split and domain: five papers where possible, with the last arXiv and biomedical groups containing three and one paper respectively. The funnel inputs include the immediately preceding and following original sentence, each clipped to 800 characters; full-paper input includes all sentences. Every method is scored against all labeled gaps in its papers.

These are exploratory results, not a clean blind test: the development split was used for model, threshold, and prompt selection, and test results were inspected in prior experiments. Labels are generated by LLMs and not fully human-validated. The six biomedical test papers overlap the SAL benchmark, but the scores below use the broader LLM-generated three-type labels rather than SAL's human limitation labels. This limits any claim of human-verified accuracy.

## Original test split — 34 papers

| Method | TP | FP | Precision | Recall | F1 | Target sentences sent | Qwen input tokens | Qwen output tokens |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Full papers | 458 | 83 | 84.66% | 68.98% | 0.7602 | 11,741 | 611,338 | 144,104 |
| Zero-shot NLI + Qwen | 498 | 190 | 72.38% | 75.00% | 0.7367 | 2,522 | 327,681 | 33,119 |
| Fine-tuned NLI + Qwen | 501 | 180 | 73.57% | 75.45% | 0.7450 | 1,998 | 262,899 | 28,861 |

There are 664 labeled gaps in the test papers. Fine-tuned NLI achieves the highest recall and uses 57.0% fewer Qwen input tokens than full-paper prompting, but full-paper Qwen has the highest measured precision and F1. Counting input and output Qwen tokens together, the fine-tuned funnel uses 61.4% fewer tokens (291,760 vs 755,442), excluding NLI and preprocessing. The two NLI variants are close; this experiment does not establish statistical significance.

Their grouping and output format changed, so this run does not isolate the effect of output format from group composition.

## Validation and reproducibility

All 48 group/method outputs contain one validated decision for every supplied input. Two development full-paper outputs also contained one extra out-of-input ID, marked false. The original strict validation rejected and retried each output, with identical responses; a recovery rule adopted after the first failure excluded only extra IDs when every actual input ID was present exactly once. The original failed outputs and recovered records are both preserved. Missing, duplicated or malformed input decisions were not accepted. The per-call files record all attempts, and the token totals above include retries (none occurred on the test split). Full-paper requests also include formatting and classification of figures, references and other sentences; funnel Stage A filters those before NLI.

`plan.json` fixes groups, prompts, thresholds and data hashes; `preflight.json` checks all 48 inputs fit with the output budget. `summary.json` and `scripts/bench/five_paper_68_summary.py` give split/domain counts and all-attempt token totals. The existing shared 27B service was used; no GPU service was started or stopped.
